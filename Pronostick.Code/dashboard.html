🧪 Un secondo motore, a costo zero
Pronostick.Code è un laboratorio locale gemello del Pronostick reale: stesso obiettivo (generare e verificare pronostici sportivi con l'AI), ma un motore diverso — Claude Code con WebSearch nativo, incluso nel piano Pro, invece dell'API Anthropic a pagamento usata dall'app.

Nasce per affinare il ragionamento di analisi (e la logica di verifica/apprendimento) senza consumare credito API ad ogni iterazione, prima di eventualmente portare un miglioramento scoperto qui nel Pronostick reale.

Non è solo un esperimento: si usa esattamente come il Pronostick reale, comprese le giocate con soldi veri — cambia solo il motore (Claude Code invece dell'API a pagamento). 💡 Stessa qualità di analisi che ti aspetteresti dall'app, stesso tracciamento di importi/ROI reali qui nella Dashboard.
🔒 Isolato al 100% dal Pronostick reale
Nessun collegamento a index.html, localStorage o Firestore. Dati e "memoria" (lezioni apprese) vivono solo in questa cartella, in Pronostick.Code/pronostici/.

Un eventuale miglioramento di ragionamento scoperto qui va portato nel Pronostick reale sempre a mano (nel buildPrompt() di index.html) — mai un sync automatico tra le due basi di codice.
⚡ Analizzare una partita
  1. Apri una sessione Claude Code in questo repository.
  2. Chiedi di analizzare una partita, es. "analizza Inter vs Milan (calcio, Serie A)" — la skill analizza-locale si attiva da sola.
  3. Claude Code dichiara cosa sta cercando, poi cerca dati reali via WebSearch (forma, notizie, quote se disponibili) e applica le lezioni apprese dai pronostici già verificati.
  4. Il pronostico viene salvato in un file .json dentro pronostici/, e ti viene comunicato il pronostico principale + il percorso del file.
💡 Non serve incollare dati o compilare form — basta chiederlo in linguaggio naturale, come per qualsiasi altra richiesta a Claude Code.
✅ Verificare un pronostico
  1. Dopo che la partita si è giocata, chiedi di verificarla — per nome squadre o per id (es. "verifica Inter vs Milan").
  2. Claude Code cerca il risultato reale via WebSearch, confronta col pronostico salvato e scrive un giudizio (indovinato/sbagliato) + una nota di apprendimento.
  3. Il file viene aggiornato con lo stato finale: Vinto Perso o pareggio.
Se il risultato non si trova ancora, Claude Code lo dichiara esplicitamente e lascia lo stato invariato — In Attesa — invece di inventare un esito.

Se hai più pronostici da verificare tutti insieme, Claude Code te li elenca e aspetta conferma su quali processare: mai un batch automatico silenzioso.
💰 Quanto costa
Zero. Sia l'analisi che la verifica passano dal piano Claude Pro (WebSearch + ragionamento inclusi), senza nessuna chiamata all'API Anthropic a pagamento del Pronostick reale.
📄 Un file per partita
Ogni pronostico è un file .json in pronostici/, con lo stesso livello di dettaglio dell'app: dati partita, pronostico principale, mercati (Over/Under, 1X2, GG), come giocarla, e uno stato che passa da In Attesa a Vinto/Perso/pareggio dopo la verifica.

Se un dato non si trova durante la ricerca, il campo note_mancanti lo segnala esplicitamente invece di essere riempito con un valore inventato. ⚠️ Questi file sono gitignored di proposito — sono pronostici/giudizi generati, non dati definitivi, e non vanno committati nel repository.
🧠 Come funziona la "memoria"
Prima di ogni nuova analisi, Claude Code rilegge i pronostici già verificati (al massimo le 8 lezioni con priorità più alta: stesso sport+competizione prima, poi solo stesso sport, poi tutti) e li usa come contesto per correggere bias ricorrenti — stessa logica della Memoria AI del Pronostick reale, ma isolata qui.

Più verifiche completi, più il ragionamento delle analisi successive si affina.
🔧 Correggere il ragionamento — !patch
Se qualcosa nel processo non funziona come vorresti (schema dati da correggere, logica delle lezioni da aggiustare, output malformato), scrivi !patch nella sessione: Claude Code rivede cosa non ha funzionato e propone una modifica alla skill analizza-locale. Dopo la tua conferma, la applica e aggiorna il changelog della skill.
📊 Vedere tutti i pronostici in un colpo
  1. Clicca il tab "📊 Dashboard" qui sopra (questa stessa pagina).
  2. Clicca "📂 Apri cartella pronostici" e seleziona la cartella Pronostick.Code/pronostici/ dal selettore nativo del sistema operativo, concedendo il permesso di lettura/scrittura quando richiesto.
  3. Vedrai le card di ogni pronostico con stato, filtri (Tutti/In Attesa/Vinti/Persi) e dettaglio espandibile con un click.
⚠️ Funziona solo su Chrome o Edge: usa la File System Access API per leggere e scrivere la cartella direttamente dal disco, senza upload né server. Altri browser mostrano un avviso "non supportato".
💰 Tracciare le giocate reali
Quando decidi di scommettere davvero su un pronostico, apri il dettaglio della card e compila Importo € e Quota reale — si salvano subito nel file .json corrispondente (una spunta "✓ salvato" conferma la scrittura, un avviso rosso segnala se non è andata a buon fine).

In cima alla dashboard trovi i KPI aggiornati (Investito, Vinto, Profitto, ROI Reale) e il grafico di andamento ROI nel tempo — stessa logica delle Statistiche nel Pronostick reale, calcolati solo sui pronostici già verificati (Vinto/Perso) con un importo inserito. 💡 Importo e quota li inserisci solo tu quando piazzi davvero la giocata — la skill di analisi non li tocca mai.
❓ Domande Frequenti
È collegato in qualche modo al Pronostick reale? ▼
No, mai. Dati, memoria e ragionamento restano completamente separati — niente localStorage, niente Firestore, niente API key. Un eventuale miglioramento va portato nel Pronostick reale sempre a mano, mai in automatico.
Costa qualcosa usarlo? ▼
No, zero. È incluso nel piano Claude Pro — nessuna chiamata all'API Anthropic a pagamento del Pronostick reale, né per l'analisi né per la verifica.
Posso committare i pronostici generati su Git? ▼
No — la cartella pronostici/ è gitignored di proposito. Sono dati generati/giudizi in evoluzione, non dati definitivi del progetto, stesso principio già usato per i dati del progetto gemello Bracco.
Cosa succede se Claude Code non trova il risultato di una partita da verificare? ▼
Non inventa nulla — te lo segnala esplicitamente e lascia lo stato invariato (In Attesa), da riprovare più avanti quando il risultato sarà reperibile.
Posso modificare come ragiona l'AI durante l'analisi? ▼
Sì — scrivi !patch nella sessione. Claude Code rivede cosa non ha funzionato e propone una modifica precisa alla skill analizza-locale; dopo la tua conferma la applica.
A cosa serve la cartella _inbox, non la vedo usata? ▼
Non è ancora usata da questa dashboard, che legge direttamente da pronostici/ — resta riservata a un eventuale uso futuro (es. richieste in coda). Oggi non serve: basta chiedere direttamente a Claude Code di analizzare o verificare una partita in una sessione con la skill attiva.
La dashboard mostra "browser non supportato", cosa faccio? ▼
Apri il file con Chrome o Edge su desktop — sono gli unici browser che supportano la File System Access API usata per leggere e scrivere la cartella pronostici/ direttamente dal disco.
Devo inserire un importo su ogni pronostico? ▼
No — solo su quelli su cui decidi davvero di scommettere. Senza importo, il pronostico resta comunque visibile e verificabile, semplicemente non entra nel calcolo di KPI/ROI (che considerano solo pronostici verificati con un importo inserito).
